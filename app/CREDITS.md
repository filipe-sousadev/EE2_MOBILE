# Credits

## Original game files used
None. The target folder `/home/ar1m4/Downloads/EE2/` contained only:
- `GOG_Galaxy_Empire_Earth_2_Gold_Edition.exe` — a GOG Galaxy downloader, not the game (not used).
- `empire-earth-2-ee2eu.yml` — a Lutris install script (read only to learn that the game files were absent; not copied).

For the Deep-mode study, a UPX-unpacked copy of that downloader was decompiled (kept outside the app, in the project's
checks folder). It is GOG's Galaxy web installer and holds no game rules, art or data, so nothing from it is in this build.

No textures, models, sounds, music, fonts, maps or data from any existing game are included.

## Everything in this build
- Code, rules and numbers: written for this project (Godot 4.4, GDScript).
- Graphics: shapes drawn by code at run time.
- Font: Godot's built-in default font.
- Engine: Godot Engine 4.4.1 (MIT licence).
